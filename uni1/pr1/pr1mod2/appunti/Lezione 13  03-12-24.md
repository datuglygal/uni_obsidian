### Ricorsione
un algoritmo ricorsivo è definito in termini di se stesso, ma deve terminale, deve quindi prevedere una condizione di terminazione chiamato caso base.

es. fattoriale di un numero

$$
n! = n \cdot (n-1) \cdot (n-2) \cdot \dots \cdot 1
$$

```C
int main (){
int f=fatt(3);}

int fatt( int n){
if (n==0)
return 1;
else 
return n*fatt(n-1);
}
```
