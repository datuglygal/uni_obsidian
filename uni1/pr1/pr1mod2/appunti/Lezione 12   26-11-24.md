### Allocazione dinamica della memoria

`sizeof` fornisce la dimensione in byte di una certa espressione

```C
int a=0;
size_t dim = sizeof(a); //size_t è un tipo di intero senza segno
```

un intero avrà dimensione 4
un double // 8
(ma dipende dal computer e dal compilatore)

potremmo utilizzarlo anche per vedere la dimensione di un array, ma è sconsigliato perchè, ad esempio, utilizzando un array in una subroutine, quando lo passiamo alla subroutine, verrà restituita la grandezza del puntatore e non dell'array in sé.

##### autovalutazione
- la malloc alloca in memoria un numero di byte pari a un parametro fornito, e rende un puntatore al tipo void che indica un generico indirizzo di memoria (il cast lo facciamo noi dopo)
- la calloc alloca in memoria n elementi consecutivi, ciascuno dei quali ha dimensione size (espressa in byte) e pone a zero tutto lo spazio allocato (non a NULL)
- con la calloc i valori vengono inizializzati e perciò è molto più efficiente
- è necessario inizializzare un puntatore a NULL per evitare che il puntatore punti a una posizione di memoria non valida, prevedendo comportamenti indefiniti
- un array statico ha dimensione fissa definita al tempo della compilazione, mentre la dimensione di un array dinamico è definita a runtime
- calloc e malloc restituiscono un puntatore a void
- la funzione free serve a deallocare lo spazio del puntatore precedentemente allocato e prevenire problemi di memory leak
- una matrice in memoria viene rappresentata in maniera sequenziale, quindi con uno spazio contiguo di R*C celle
- è possibile allocare uno spazio contiguo di R*C celle e accedervi tramite puntatore, oppure allocare uno spazio contiguo di R righe e per ogni riga si allocano le C colonne
- un puntatore a puntatore è una variabile che contiene l'indirizzo di un altro puntatore

        case LIBRO://libro, eta minima 6  
            giocattolo->eta_minima=ETA_LIBRO;  
        break;  
        default:  
            printf("\n Il tipo di gioco inserito non e' valido");  
        break;  
    }  
}  
  
/** === ESERCIZIO 6 (Distribuzione giocattoli) [8pt] ===================================================================  
 * Scrivere una subroutine babboNatale che, ricevuti in ingresso un valore intero n_bambini, un array di elementi di tipo * Bambino, un valore intero n_giocattoli, un array di elementi di tipo Giocattolo, selezioni un giocattolo casuale * per ogni bambino. Nel caso in cui il giocattolo non sia adatto al bambino, il bambino rimarrà senza giocattolo. * Tenere anche conto che: * - i giocattoli devono essere assegnati casualmente e lo stesso giocattolo puo' essere assegnato a piu' bambini; * - un bambino non puo' ricevere un giocattolo non adatto alla sua eta'; * - un bambino non puo' ricevere piu' di un giocattolo; * - l'eta' minima di un PELUCHE e' 0, di un VIDEOGAME e' 12, di un GIOCO_TAVOLO e' 8, di una PALLA e' 2 * e di un LIBRO e' 6; * OPZIONALE: realizzare una subroutine verificaEta che, ricevuti un Giocattolo e un Bambino, verifichi * se il giocattolo e' adatto ad un bambino, tenendo conto dell'eta' minima del giocattolo e dell'eta' del bambino. */  
bool verificaEta(Giocattolo* giocattolo, Bambino* bambino) {  
    bool idoneo=false;  
    if((bambino->eta)>=(giocattolo->eta_minima)) {  
        idoneo=true;  
    }else {  
        idoneo=false;  
    }  
    return idoneo;  
}  
  
void babboNatale( int n_bambini, Bambino bambini[], int n_giocattoli, Giocattolo giocattoli[] ) {  
    int gioco_casuale=0;  
  
    for(int i=0; i<n_bambini; i++) {  
        gioco_casuale=rand()%(n_giocattoli);  
        if(verificaEta(&giocattoli[gioco_casuale], &bambini[i])==true) {  
            bambini[i].giocattolo=&giocattoli[gioco_casuale];  
        }else {  
            bambini[i].giocattolo=0;  
        }  
    }  
}
